## 画面構成

### ヘッダー

・画面上部の左にアプリ名とモード「OZ-9 COLOR SEQUENCER <console mode>」を表示する。
・画面上部の右に「日付 時刻 パッド番号 カラーコード」を表示する。表記例：`2026/10/14 13:30:00:00 PAD.01 #00A8EB`
・時刻は端末の時計を使う。~~末尾2桁（`:00`）が1/100秒かフレーム数かは未決定。~~
・末尾2桁（`:00`）は1/100秒の表記だが、1パッドの表示時間（0.5秒）単位で動かす。そのため表示は `00` か `50` のどちらかになる。
・パッド番号とカラーコードは、RUN状態で現在実行中のパッドのものを表示する。

・RUN状態で現在シーケンスパッドに割り当てられてる色を表示する。

・時刻、パッド番号、カラーコードはヘッダーに表示する。URLはQRコード欄で扱う。

### audienceのURLとQRコード

・ログインしたアカウントごとに、audienceページのURLを1つ割り振る（ログイン機能を作るまでは、URLは1つで固定）。
・アウトプットモニターの右に、audienceページのURLのQRコードを表示する。
・QRコードは外部APIを使わず、ライブラリで作成する。
・スマートフォンでは、QRコードを長押しすると画像の保存とURLのコピーができる。
・PCでは、QRコードをクリックするとURLをコピーする。
・LOCK状態でもQRコードは操作できる（LOCKを適用しない）。

### シーケンスパッド

・12個のパッドを配置。1～12番まで番号が割り振られ、RUNを押すと1番から順にシーケンスを開始。RUNボタンをOFFにするとシーケンスを停止し1番に戻る。  
・現在表示しているパッドには赤い輪郭線を設ける。  
・カラーパレットから色をドラッグすると色がアサインされる。  
・Shiftキーを押すと、パッドを複数選択できる。まとめて同じ色をアサインする。スマートフォンの場合、ダブルタップでShiftと同じ複数選択。

・RUN状態でアサインすると直ちに色が変更されず仮アサインとなる。
・仮アサインの色もサーバーに保存する。
・consoleを再読み込みしたときは、サーバーから状態（RUN中か停止中か、t0、本アサイン、仮アサイン）を読み込み、画面を元に戻す。

・パッドを右クリックすると、アサインされた色の編集と色の削除のメニューを表示。
~~・色がアサインされてないときはSMPTEカラーバーを表示。~~
・色がアサインされてないパッド（初期状態）は、暗い背景に赤い斜線で表示する。
・パレット12番のSMPTEカラーバーをアサインしたパッドは、SMPTEカラーバーを表示する。
・一つのパッドの時間は0.5秒。

### RUNボタン

・RUNボタンを押すとシーケンスが開始される。
・RUNが押された時点で、端末時計をもとに時刻が割り振られスケジュールとしてサーバーに送信される。~~20ループ分のスケジュールを作成する。~~
~~・RUNを押すと、2秒後を開始時刻として送信する~~
~~・RUNボタンを押してから2秒後をt0とする。~~
・RUNを押した時刻を0.5秒単位で切り上げ、そこから2秒後を開始時刻 t0 とする。
　・小数部分がちょうど .0 → そのまま
　・小数部分が .0 より大きく .5 以下 → その秒の .5
　・小数部分が .5 より大きい → 次の秒の .0
　・例：13:30:00.37 に RUN → 13:30:00.50 に切り上げ → t0 = 13:30:02.50
　・例：13:30:00.81 に RUN → 13:30:01.00 に切り上げ → t0 = 13:30:03.00
・RUNを押してから開始までは、必ず2.0〜2.5秒になる。
・これにより、時刻表示の末尾2桁（00 / 50）とパッドの切り替えが一致する。
・SWITCHの t0（ループの切れ目）も、元の t0 から6秒の倍数後なので自動的に0.5秒単位に揃う。
・RUNをOFFにしたら、「状態：停止」をサーバーに送り、版番号を+1する。

> 今は RUN を押した瞬間が 𝑡0 です。この場合、audience がポーリングで schedule を受け取るのは数秒後になります。そのため、audience は途中のパッドから表示を始めます。

### SWITCHボタン

~~・スイッチボタンを押すと、仮アサイン中の色が本アサインとなり、scheduleファイルの書き換えが行われる。サーバーも書き換える。~~
・スイッチボタンを押すと、本アサインのカラーコードと仮アサインのカラーコードを入れ替える。scheduleファイルの書き換えが行われる。サーバーも書き換える。
・入れ替えなので、もう一度SWITCHを押すと元の色に戻る（A/Bの切り替えとして使える）。
・仮アサインがないパッドは入れ替えず、本アサインの色のまま。
・パッドの表示は、左上が本アサイン、右下が仮アサイン。SWITCHで左上と右下の色が入れ替わる。
・スイッチボタンを押して 2秒以上先の、最初のループの切れ目を新しい 𝑡0 にする。

> > console で SWITCH を押したら、新しい色を「今すぐ」ではなく、「2秒後の、ループの切れ目から有効」 として登録します。

### LOCKスイッチ

・QRコードの下に配置するトグルスイッチ。
・LOCK状態では、次の操作をできなくする。
　・RUNボタン
　・SWITCHボタン
　・パッドへの色のアサイン（ドラッグ、複数選択でのアサイン、右クリックメニューでの色の編集・削除）
・LOCK状態でもQRコードは操作できる。
・LOCK中もシーケンスの実行（RUN状態）はそのまま続く。
~~・カラーパレットの色調整（カラーピッカー）をロックするかは未決定。~~
・LOCK状態でもカラーパレットの色は編集できる（カラーピッカーにはLOCKを適用しない）。
