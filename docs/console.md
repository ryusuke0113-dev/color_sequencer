# コンソール画面について

## 画面構成

### カラーパレット

・12区画のカラーパレット。内、一つにSMPTEカラーバーを割り当てる。 ・各区画には白、黒、赤、青、緑、黄、茶、紫、ピンク、橙、灰色の基本色を配置。ダブルクリックでカラーピッカーを表示し任意の色を調整できる。スマートフォンの場合、ダブルタップで色調整画面表示。

### アウトプットモニター

・RUN状態で現在シーケンスパッドに割り当てられてる色を表示する。
・audienceページのURL、現時刻、表示中のカラーコードが小さい文字でアウトプットモニター下部に表示される。
・右クリックで、audienceページのURLをコピーする。

### シーケンスパッド

・12個のパッドを配置。1～12番まで番号が割り振られ、RUNを押すと1番から順にシーケンスを開始。RUNボタンをOFFにするとシーケンスを停止し1番に戻る。  
・現在表示しているパッドには赤い輪郭線を設ける。  
・カラーパレットから色をドラッグすると色がアサインされる。  
・Shiftキーを押すと、パッドを複数選択できる。まとめて同じ色をアサインする。スマートフォンの場合、ダブルタップでShiftと同じ複数選択。

・RUN状態でアサインすると直ちに色が変更されず仮アサインとなる。

・パッドを右クリックすると、アサインされた色の編集と色の削除のメニューを表示。
・色がアサインされてないときはSMPTEカラーバーを表示。
・一つのパッドの時間は0.5秒。
・シーケンス

### RUNボタン

・RUNボタンを押すとシーケンスが開始される。
・RUNが押された時点で、端末時計をもとに時刻が割り振られスケジュールとしてサーバーに送信される。~~20ループ分のスケジュールを作成する。~~
・RUNを押すと、2秒後を開始時刻として送信する
・RUNボタンを押してから2秒後をt0とする。

> 今は RUN を押した瞬間が 𝑡0 です。この場合、audience がポーリングで schedule を受け取るのは数秒後になります。そのため、audience は途中のパッドから表示を始めます。
> ~~全員の画面で1番のパッドからそろって始めたいなら、RUN も SWITCH と同じく「数秒後から開始」にするとよいです。こうすると RUN と SWITCH の仕組みが同じになり、実装も楽になります。

### SWITCHボタン

・スイッチボタンを押すと、仮アサイン中の色が本アサインとなり、scheduleファイルの書き換えが行われる。サーバーも書き換える。
・スイッチボタンを押して 2秒以上先の、最初のループの切れ目を新しい 𝑡0 にする。

> > console で SWITCH を押したら、新しい色を「今すぐ」ではなく、「2秒後の、ループの切れ目から有効」 として登録します。
