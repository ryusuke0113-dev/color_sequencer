# スケジュールについて
・consoleでRUN実行すると、パッドにこれから実行されるシーケンスの時刻が計算される。

> パッドの現在値 = ⌊ (t − t0) / 0.5 ​​⌋ mod12
今回1パッドの表示時間は0.5sec固定とする。可変速度は行わない。

・色はカラーコードを表記

> 版番号（サーバーが保存のたびに +1、ファイルに保存）
> 開始時刻 𝑡0（ミリ秒で表すと JavaScript と相性が良い）
> 12色のカラーコード（色なしのパッドをどう表すかも決める）
> 状態（RUN 中か停止中か）

アサインなし,RUN状態がOFFの場合SMPTEカラーバーを表示
