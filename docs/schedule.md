# スケジュールについて
・consoleでRUN実行すると、パッドにこれから実行されるシーケンスの時刻が計算される。

> パッドの現在値 = ⌊ (t − t0) / 0.5 ​​⌋ mod12

今回1パッドの表示時間は0.5sec固定とする。可変速度は行わない。

・色はカラーコードを表記

> 版番号（サーバーが保存のたびに +1、ファイルに保存）
> 開始時刻 𝑡0（ミリ秒で表すと JavaScript と相性が良い）
> 12色のカラーコード（~~色なしのパッドをどう表すかも決める~~ → 未アサインは null に決定。下の「色のデータの書き方」を参照）
> 状態（RUN 中か停止中か）

・t0 は必ず0.5秒単位に揃えた時刻にする（RUNを押した時刻を0.5秒単位で切り上げ、2秒足したもの。詳しくは console.md のRUNボタンを参照）。
・仮アサインの12色もサーバーに保存する。書き方は本アサインと同じで、仮アサインがないパッドは null。
・RUNをOFFにしたら、状態を「停止」にして保存し、版番号を+1する。
・仮アサインを保存したときも版番号を+1する（audienceの表示は変わらない）。
・【AI】カラーパレットの12区画の色もサーバーに保存する。12番は常に "SMPTE"。パレットを保存したときも版番号を+1する。
・【AI】SWITCHしたときは「切り替え前の本アサイン」も保存する。audienceは新しい t0 より前ならこの色を表示する（途中から開いたaudienceでも正しく表示するため）。

~~アサインなし,RUN状態がOFFの場合SMPTEカラーバーを表示~~
・パッドの状態は「通常の色」「SMPTEカラーバー」「未アサイン」の3種類。
・未アサインのパッドは、console・audienceともに暗い背景に赤い斜線を表示する。
・RUN状態がOFFのとき、スケジュールがないときは、SMPTEカラーバーを表示する。

### 色のデータの書き方

・12個のパッドの色は、パッド1から順に12個並べたリストで書く。
・パッドの状態ごとの書き方は次のとおり。

| パッドの状態 | データの書き方 | 例 |
|---|---|---|
| 通常の色 | カラーコード（`#` で始まる6桁） | `"#C00000"` |
| SMPTEカラーバー | 決まった文字 `"SMPTE"` | `"SMPTE"` |
| 未アサイン | `null`（Pythonでは `None`） | `null` |

・例：パッド1が赤、パッド2が未アサイン、パッド3がSMPTEカラーバーの場合
　`["#C00000", null, "SMPTE", ...]`
・初期状態（すべて未アサイン）は、12個すべて `null`。
