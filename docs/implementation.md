# 実装時にAIが補完した仕様

このファイルはすべてAI（Cursor）が書いたもの。MDに書かれていなかった部分を、実装のために補った内容をまとめる。変えたい項目があれば、このファイルを直してからコードを直す。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `app.py` | Flaskのルート（ログイン、console、audience、API、QRコード） |
| `database.py` | アカウントとscheduleをSQLite（`data/app.db`）に保存 |
| `sequence.py` | scheduleのデータと、RUN・STOP・SWITCH・アサインのルール |
| `static/js/sequencer.js` | consoleとaudienceで共通の処理（色の計算、時刻表示、ポーリング） |
| `static/js/console.js` | console画面の操作 |
| `static/js/audience.js` | audience画面の表示 |

## scheduleに保存する項目

| 項目 | 内容 |
|---|---|
| `version` | 版番号。サーバーが保存のたびに+1 |
| `state` | `"run"` か `"stop"` |
| `t0` | 開始時刻（ミリ秒）。停止中は `null` |
| `colors` | 本アサインの12色 |
| `temp_colors` | 仮アサインの12色。仮アサインがないパッドは `null` |
| `prev_colors` | SWITCH前の本アサイン。新しい t0 より前はこの色を表示する |
| `palette` | カラーパレットの12色。12番は常に `"SMPTE"` |

audienceには `version` `state` `t0` `colors` `prev_colors` だけを渡す。

## 時計

・端末の時計をそのまま使うと、端末ごとに0.数秒ずれることがある。そこで、ページを開いたときと60秒おきにサーバーの時刻を5回取得し、通信時間が一番短かった回から「端末の時計とサーバーの時計の差」を計算して補正する。
・時刻表示やパッドの計算は、補正した時刻で行う。サーバーに接続できないときは端末の時計のまま。

## console の操作

・パッドをクリック（タップ）すると選択。そのあとパレットをクリックすると、選択中のパッドにその色をアサインする（スマートフォンでドラッグの代わりに使う）。
・パッドをダブルクリック（ダブルタップ）すると、Shift+クリックと同じく複数選択に追加する。
・パッド・パレット以外の場所をクリックするか、Escキーで選択を解除する。
・右クリックメニュー
　・色を編集：停止中は本アサイン、RUN中は仮アサインの色をカラーピッカーで決める。
　・色を削除：停止中だけ表示。本アサインを未アサインにする。
　・仮アサインを取り消す：仮アサインがあるパッドだけ表示。
・RUN中に色を削除する操作はない（仮アサインの `null` は「仮アサインなし」の意味のため）。
・SWITCHは、LOCK中・停止中・切り替え待ち中（新しい t0 の前）・仮アサインがないときは押せない。押すと理由を表示する。
・切り替え待ちの間、SWITCHボタンは黄色の枠になる。
・RUNをOFFにしても仮アサインは残す。
・LOCKの状態はブラウザ（localStorage）に保存する。サーバーには送らない。

## 表示

・ヘッダーのカラーコード欄：未アサインは `NO ASSIGN`、SMPTEカラーバーは `SMPTE`、待機中は `PAD.-- STANDBY`。
・audienceはタップで全画面表示になり、対応している環境では画面が消えないようにする（Wake Lock。HTTPSでないと使えないことが多い）。
・audienceはサーバーに接続できない間、最後に受け取ったscheduleで表示を続け、画面左上に注意を出す。

## URLとQRコード

・consoleを `localhost` で開いている場合、QRコードのURLはこのPCのLANのIPアドレスに置き換える（スマートフォンから開けるようにするため）。
・QRコードは `qrcode` ライブラリでSVGとして作る（外部APIは使わない）。

## ログイン

・メールアドレスとパスワード（8文字以上）で登録。パスワードはハッシュ化して保存する。
・ログイン状態は30日間保持する。
・audienceのURLは登録時にランダムな文字列で作る（`/audience/<文字列>`）。HTMLファイルは作らず、同じテンプレートを使う。
